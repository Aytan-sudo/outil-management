Ce projet vise à la réalisation d'une application de bureau sous mac (python probablement +/- version web local si nécessaire pour simplifier les outils) qui centralise des outils d'aide au leadership / management. L'appli se présente sous la forme d'une page d'accueil qui affiche les outils sous forme de bouton cliquable pour se rendre à la page dédié. Chaque page d'outil est ensuite utilisable directement. 
Les outils suivants osnt à proposer :
1) matrice d'Eisenhower : un outil pour rentrer ses taches visuellement sous forme de vignette avec un score de important / urgence (sur 20) et les affecter dans les catégories concernés. La liste de tache est visible à droite, la matrice sur 75% de l'écran a gauche.
2) Graphique SMART et délégation de tâches
3) modèle TKI : rentrer ses scores et évaluer quelle attitude face à situation donnée (exemple : enjeu fort + relation importante → collaboration / enjeu fort + urgence → compétition/décision / enjeu faible → accommodation possible / problème secondaire → évitement parfois parfaitement rationnel)
4) Matrice des conflits par acteurs (alliés, adversaires, opportunistes, ennemis), à voir comment la rendre bien utilisable ?
5) Profil psychologique et DISC (affecter un score sur chaque axe a des personnes et les positionner sur le DISC)
6) Page sur les cinq motivations individuelle e(sois parfait(e), sois fort(e), sois rapide, etc ...
Dans un deuxième temps, l'idéal serait d'héberger cet outil (sur git ?) pour le rendre consultable depuis le web ou un smartphone, si possible avec cookies locaux pour gérer la personnalisation de chacun ?
