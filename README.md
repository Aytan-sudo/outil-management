# Outil Management

Boîte à outils de leadership / management : matrice d'Eisenhower, SMART &
délégation, modèle TKI, matrice des conflits, profil DISC, drivers.

Site statique, données stockées localement dans le navigateur (`localStorage`),
aucune donnée envoyée sur un serveur.

**Utiliser l'outil** : https://aytan-sudo.github.io/outil-management/

**Développer en local** : `python3 -m http.server 8000` puis
http://localhost:8000
